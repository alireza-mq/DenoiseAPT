# CATSv2 replay data notice

`data/prepared/tsb_ad_cats_heldout_replay.npz` contains a derived 512-time-point
window from the CATSv2 simulated-telemetry dataset, together with controlled
corruptions and frozen benchmark outputs generated for the DenoiseAPT
demonstration.

CATSv2 was created by Patrick Fleith and Solenix. The source dataset is
distributed under the Creative Commons Attribution 4.0 International license:

- Dataset record and citation: https://doi.org/10.5281/zenodo.7646897
- License: https://creativecommons.org/licenses/by/4.0/

The replay is provided with attribution under those terms. It is an
illustrative, post-hoc selected held-out replay rather than a new benchmark, and
it is not covered by the repository's MIT license. CATSv2 is simulated
telemetry; it must not be described as a real sensor record.
